Put the hero videos in this folder with these exact names:

  men-hero.mp4     plays behind the Men's store home page headline
  women-hero.mp4   plays behind the Women's store home page headline

Tips: MP4 (H.264), 1920x1080 or 1280x720, 10-20 seconds that loop smoothly,
no sound needed (it plays muted), keep each file under about 8 MB so it loads fast.
